## Data

This folder contains the dataset used in this project.

- `WA_Fn-UseC_-HR-Employee-Attrition.csv` — IBM HR Analytics Employee Attrition dataset (publicly available on [Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset))

### About the dataset
The dataset contains information on 1,470 employees across 35 features, including demographic attributes (age, gender, marital status), job-related features (department, job role, monthly income, years at company), and a binary target variable **Attrition** (Yes/No) indicating whether the employee left the company.
