# Equidad Algorítmica [[Fairness]]
Las fuentes exploran cómo los sistemas de IA pueden discriminar y cómo los contrafactuales ayudan a detectar y mitigar este problema.

- **Equidad Contrafactual:** Un modelo es justo si la predicción para un individuo no cambiaría si su atributo protegido (como raza o género) fuera diferente.
  thats so cool! 

- **Equidad de Recurso (FACTS):** Analiza si el "costo" o el esfuerzo necesario para revertir un resultado negativo es el mismo para diferentes subgrupos protegidos. Por ejemplo, se investiga si es más difícil para las mujeres que para los hombres obtener un recurso que cambie una denegación de préstamo
